How the forecast is produced

  1. The school's recorded history is loaded from the active dataset.
  2. The same features used in training are built for each forecast day.
  3. The saved, already-trained model predicts demand. No model is trained here.
  4. A rule-based safety buffer turns predicted demand into a recommended preparation quantity.
  5. The result is saved to the forecast history.

Read results with care

  • Forecasts are estimates, not guarantees.
  • Multi-day forecasts reuse earlier predictions as if they were observed, so uncertainty grows with the horizon. Treat 30-day forecasts as directional.
  • Horizons count school days (Monday–Friday).
