{% comment %} Runs before any stylesheet paints so the page never flashes the wrong theme. Signed-in users: the theme saved in Settings (html[data-theme-pref], rendered by the server) wins, and is copied to localStorage so the login page and Django admin match after logging out. Signed out: the "theme" localStorage key (shared with Django admin's toggle) decides. "light"/"dark" is an explicit choice; anything else follows the OS setting. {% endcomment %}
